# C3 prior dictionary

This directory contains the first static JSON Schema contract for the future c_3 prior semantic dictionary.

The schema is a hard skeleton for future YAML dictionary work. It defines required sections, reusable entry shapes, enum families, forbidden runtime field families, and stop-line fields.

This directory does not contain a YAML dictionary. It does not contain a validator script. It does not authorize prototype code, renderer behavior, runtime behavior, formula movement, c_4 implementation, c_1 integration, c_2 integration, readiness claims, visual parity claims, correctness claims, leak-fix claims, performance claims, or runtime replacement.

## Files

```text
c3_prior_semantic_dictionary.schema.v0.json
```

## Boundary

The schema is a docs/test-only contract artifact. It is not a runtime API and must not be consumed as implementation authorization.
