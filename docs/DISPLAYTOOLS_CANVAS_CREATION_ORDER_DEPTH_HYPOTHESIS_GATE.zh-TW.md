本文件是 docs/test-only 的 canvas creation order depth hypothesis gate。它把 u_o 補充的 RRKAL 畫布原始想像轉成可檢驗的 design-intent axis：畫布生成順序接近舊約創世記式的堆疊，從混沌、光、世界框架、地形、邊界、受造物，到選取與治理。

## Canvas creation order matrix

| Depth | Layer | Canvas role | C3 bias |
| --- | --- | --- | --- |
| 0 | `chaos_or_raw_data` | pre-canvas disorder / unshaped data | outside canvas or raw source pressure |
| 1 | `light_sun_starfield` | light, stars, solar/time orientation | world-law / deep frame semantics, not ordinary decoration |
| 2 | `world_frame_projection` | world visibility, coordinate frame, observer law | `core_interface_only` |
| 3 | `terrain_bathymetry` | earth/sea shape, world body | world-body / high coupling |
| 4 | `vector_boundary_naming` | boundary, naming, separation, semantic geography | boundary / semantic geography |
| 5 | `dynamic_point_creatures` | AIS/ADS-B moving entities / created creatures | later created entities with reconstructable semantics |
| 6 | `selection_card_governance` | human/agent viewing, selection, governance, card semantics | governance/interface/cross-organ semantics |

## Layer interpretation

### `chaos_or_raw_data`

Raw provider payloads, cache/database/file inputs, and unshaped dynamic point payloads live before the canvas. This layer should not be given canvas semantics without a source boundary.

### `light_sun_starfield`

Solar, lighting, and starfield terms are treated as world-law or deep-frame semantics. They should bias toward diagnostic labels and formula stop lines, not ordinary decoration.

### `world_frame_projection`

Projection, flip, mask, globe coordinate ownership, and dynamic point projection shadow belong near observer law. This biases toward `core_interface_only` and shadow/interface design, not formula movement.

### `terrain_bathymetry`

Terrain and bathymetry are world-body surfaces. They may allow descriptor shells, but terrain sampling, shader, bump, normal, and visual behavior remain high-coupling surfaces.

### `vector_boundary_naming`

Vector overlays represent boundary, naming, separation, and semantic geography. Descriptor/policy/ledger extraction can be safe only when provider/cache, projection/mask formula, and controller mutation are excluded.

### `dynamic_point_creatures`

AIS and ADS-B moving entities are later created entities. Their semantics are more reconstructable than world-frame formulas, but runtime lineage, projection, controller, and renderer dependencies still need stop lines.

### `selection_card_governance`

Selection, card semantics, metadata, and cross-organ integration belong to viewing and governance. These should bias toward governance review, wrapper/interface design, or cross-organ handoff, not c_3-only extraction.
