# Displaytools Canvas Creation Order Depth Hypothesis Validation Gate

本文件是 docs/test-only validation gate。上一張 gate 建立了 canvas creation order depth 作為 `L1_design_intent_hypothesis`；本張不是再發明新比喻，而是用已知 c_3 岩性分類與 interface strategy 檢查它是否對齊。

本 gate 的結論最多只能升到 `L1_supported_design_intent_hypothesis`。它不升級為 `L2_local_pattern`，不升級為 universal doctrine，不取代 git history、dependency scan、ablation response 或 lithology model，也不授權 extraction。

## What is supported

The design-intent axis is useful as a secondary depth-bias axis:

- It helps explain why solar/light/starfield behaves like deep frame semantics.
- It aligns projection/flip/mask with `core_interface_only`.
- It separates terrain/bathymetry world-body coupling from later dynamic point entity semantics.
- It distinguishes vector boundary naming from provider/projection runtime.
- It places selection/card governance near schema and cross-organ review.

This is enough to support `L1_supported_design_intent_hypothesis`.

## What remains low confidence

- It does not prove religious interpretation correctness.
- It does not prove subconscious design intent.
- It does not prove implementation history.
- It does not prove coordinate correctness.
- It does not prove visual correctness.
- It does not generalize into L2 method.

## Why not L2 local pattern

Dynamic point lithology is `L2_local_pattern` only inside dynamic point. Canvas creation order is broader, less directly testable, and depends on u_o-provided design intent. It can help rank layer depth, but it is not yet a repeatable extraction method. Therefore the maximum trust level is `L1_supported_design_intent_hypothesis`.

## Why it cannot authorize extraction

Creation order describes intended canvas depth. It does not prove a source symbol is safe to move. Extraction still requires hard evidence:

- git history
- dependency scan
- ablation response
- import-boundary checker
- fixture parity
- explicit stop-line review

This gate authorizes none of those movements.

## Counterexamples

No direct counterexample was observed in the required c_3 evidence set. This absence is not a proof of subconscious design intent. It only means the current evidence aligns enough to support the hypothesis at L1.
